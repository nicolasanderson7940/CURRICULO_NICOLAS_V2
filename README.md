# 📄 Currículo — Nicolas Anderson

Um currículo digital desenvolvido com HTML e CSS para apresentar informações acadêmicas, conhecimentos e objetivos na área de tecnologia.

## 📋 Sobre o Projeto

O **Currículo Nicolas V2** é uma página web criada para organizar informações pessoais e acadêmicas em um formato visual e acessível.

O projeto apresenta um perfil de estudante de Desenvolvimento de Sistemas, destacando conhecimentos básicos em tecnologia, formação e interesses relacionados à programação.

## 🚀 Conteúdo Apresentado

* **Sobre Mim:** apresentação do perfil do estudante.
* **Objetivo:** descrição dos objetivos de aprendizado na área de tecnologia.
* **Formação Acadêmica:** informações sobre a formação escolar e técnica.
* **Conhecimentos:** apresentação dos conhecimentos e habilidades.
* **Características:** destaque de qualidades pessoais.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** estruturação das informações do currículo.
* **CSS3:** estilização e organização visual da página.

## 📁 Estrutura do Projeto

```text
CURRICULO_NICOLAS_V2/
├── CSS/
│   ├── global.css
│   ├── header.css
│   └── cards.css
└── index.html
```

* `index.html`: contém as informações apresentadas no currículo.
* `CSS/global.css`: reúne estilos gerais.
* `CSS/header.css`: organiza a estilização do cabeçalho.
* `CSS/cards.css`: contém estilos relacionados aos painéis e cards.

## ▶️ Como Executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html` no navegador.
3. Opcionalmente, utilize o Live Server para visualizar as alterações durante o desenvolvimento.

Praticar a construção de páginas web com HTML e CSS, organizar informações em componentes visuais e desenvolver uma apresentação digital do perfil acadêmico.
